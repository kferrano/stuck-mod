# Stuck Mod

## Description
Have you ever fallen into a claim hole or got trapped somewhere with no way out?  
This mod adds the `/stuck` command which safely teleports you out of such situations.

- Detects holes of different shapes (not just 1x1).
- Works in survival and adventure (configurable).
- Cooldown or once-per-life usage mode.
- Dimension restrictions (Nether/End toggleable).
- Debug logging (optional).
- Fully translatable (English + other languages).

## Usage
- Type `/stuck` when trapped.
- If conditions are met, you will be teleported upwards to the next safe block.

## Configuration
The config file (`stuckmod.toml`) lets you adjust:
- Usage mode (`COOLDOWN` or `ONCE_PER_LIFE`)
- Cooldown seconds
- Max teleport height
- Minimum wall height & radius
- Dimension restrictions
- Enable/disable debug logging
